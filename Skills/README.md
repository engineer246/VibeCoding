# Skills

This directory stores reusable workflows and task-specific skill definitions.

Add a skill when you want to capture a repeatable process that combines instructions, checks, or workflow steps. Skills are typically more procedural than prompts and may include the conditions under which they should be applied.

Examples include:

- code review workflows
- refactoring procedures
- testing playbooks
- release or validation checklists

Write skills clearly enough that they can be adapted across projects without hidden context.
