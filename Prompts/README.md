# Prompts

This directory contains reusable prompts for common AI-assisted tasks.

Use a prompt here when you want a ready-to-adapt instruction that can be copied into an AI-enabled editor or assistant. Prompts should be task-focused, include relevant placeholders, and state any assumptions or expected outputs.

Examples include:

- PR review prompts
- debugging instructions
- feature planning prompts
- code-generation templates

Keep them generic enough to reuse while still specific enough to be actionable.
