# Agents

This directory is for reusable AI agent definitions and role-specific guidance.

Use an agent here when you want to give an assistant a clear identity, responsibilities, and operating boundaries. Keep each agent focused on a well-defined role, such as review, coding, documentation, or testing.

Typical contents:

- agent instructions
- task-specific responsibilities
- guardrails and quality expectations
- examples of how to apply the agent in a workflow

Naming convention: use short, descriptive, lowercase kebab-case names.
